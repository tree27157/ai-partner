# 进程同步、互斥与信号量

## 基本概念
- **临界资源**：一次只允许一个进程访问的共享资源
- **临界区**：访问临界资源的代码片段
- **互斥**：间接制约，竞争同一临界资源，进程间无逻辑关系
- **同步**：直接制约，进程间有先后执行顺序要求

## 临界区四大原则
1. **空闲让进**：无进程在临界区时，应允许申请者进入
2. **忙则等待**：已有进程在临界区时，其他进程必须等待
3. **有限等待**：等待时间有上限，不能无限等待
4. **让权等待**：不能进入临界区时应释放CPU（不忙等）

## 实现方式
- **软件**：Peterson算法（双标志 + 轮转）
- **硬件**：关中断、TestAndSet（TSL）、Swap指令（原子操作）
- **信号量机制**（最常用，由Dijkstra提出）

## 信号量与PV操作
信号量 S：整型变量，表示可用资源数
- **P操作（wait / down）**：`S -= 1`；若 `S < 0`，进程阻塞进入等待队列
- **V操作（signal / up）**：`S += 1`；若 `S <= 0`，唤醒等待队列中一个进程

应用：
- 互斥：S 初值 = 1，PV 成对出现包住临界区
- 同步：S 初值 = 0，先 V 后 P（或根据顺序关系设置）

## 经典同步问题
1. **生产者-消费者**：互斥信号量 + 两个同步信号量（空槽数、满槽数）
2. **读者-写者**：读者优先（读进程可同时进入）vs 写者优先（公平策略）
3. **哲学家进餐**：5个哲学家5根筷子，避免死锁（最多4人同时拿、拿两根才吃、奇偶拿法）
