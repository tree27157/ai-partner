# I/O设备管理、缓冲与中断

## I/O分类
- **块设备**：磁盘、SSD，以数据块为单位访问，可随机访问
- **字符设备**：键盘、串口、打印机，以字节流访问，顺序访问
- 按共享属性：独占设备（打印机）、共享设备（磁盘）、虚拟设备（SPOOLing后的打印机）

## I/O控制方式（按发展顺序）
1. **程序直接控制（轮询）**：CPU忙等，反复查询设备状态，效率极低
2. **中断驱动I/O**：CPU发起I/O后去做别的，I/O完成发中断通知CPU；每次传输一个字节/字，中断频繁
3. **DMA 直接存储器访问**：设备与内存直接批量传输数据，CPU只在开始和结束时介入；一次传一个数据块
4. **通道方式**：独立于CPU的I/O处理器，可执行通道程序，大型机使用

## 缓冲技术
- 作用：缓解CPU与设备速度不匹配、减少中断频率、提高并行度
- 单缓冲、双缓冲、循环缓冲、缓冲池（系统公共缓冲区）

## 设备独立性（设备无关性）
- 应用程序使用**逻辑设备名**，操作系统把逻辑设备映射到物理设备
- 好处：用户程序与具体硬件解耦，换设备不用改程序

## 假脱机 SPOOLing
- 用磁盘上的输入/输出井 + 内存缓冲 + 进程模拟脱机I/O
- 把**独占设备**虚拟成**共享设备**，典型应用：打印机队列

## 中断处理流程
保存现场 → 判断中断类型 → 执行中断处理程序 → 恢复现场 → 返回被中断程序
