# 进程调度算法

## 调度目标
- CPU利用率、吞吐量、周转时间、等待时间、响应时间、公平性
- 周转时间 = 完成时间 - 到达时间；带权周转时间 = 周转时间 / 运行时间

## 调度层级
- **高级调度（作业调度）**：从后备队列选作业进入内存
- **中级调度（内存对换）**：内存与磁盘之间的对换
- **低级调度（进程调度）**：从就绪队列选进程上CPU（最频繁）

## 经典调度算法

### 1. FCFS 先来先服务
- 非抢占，按到达顺序执行
- 对长作业有利，对短作业不利（护航效应）

### 2. SJF 短作业优先
- 非抢占，选择运行时间最短的作业
- 平均周转时间最优，但存在**饥饿**问题，需要预估运行时间

### 3. SRTN 最短剩余时间优先
- 抢占式SJF，新来进程剩余时间更短则抢占

### 4. RR 时间片轮转
- 抢占式，分时系统主流
- 时间片过大退化为FCFS；过小则上下文切换开销剧增

### 5. 优先级调度
- 抢占 / 非抢占；静态 / 动态优先级
- 低优先级可能饥饿，可用**老化**（随等待时间提升优先级）解决

### 6. 多级反馈队列
- 设置多个就绪队列，优先级从高到低，时间片从短到长
- 新进程进最高优先级队列；时间片用完降级
- 兼顾长短作业、交互式进程，是实际操作系统常用方案

## 抢占 vs 非抢占
- **抢占**：高优先级 / 新短任务可打断正在运行的进程
- **非抢占**：进程主动放弃CPU（阻塞、终止、等待）才切换
