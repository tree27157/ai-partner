# 应用层：HTTP、DNS

## DNS 域名系统
- 作用：**域名 ↔ IP地址** 的分布式数据库，应用层协议
- 端口：默认 UDP 53；响应超过512字节（或区域传送）用 TCP 53
- 查询方式：
  - **递归查询**：客户端 → 本地DNS服务器（服务器替客户端逐级查完再返回）
  - **迭代查询**：本地DNS服务器 → 根/顶级/权威服务器，逐个"指引"（返回下一步地址）
- 实际过程：客户端到本地DNS是递归，本地DNS到根服务器是迭代
- 域名结构：根 → 顶级域（.com/.cn）→ 二级域 → 三级域
- DNS缓存：各级服务器和主机都有缓存，减少重复查询

## HTTP 超文本传输协议
- 基于 **TCP**，默认 **80** 端口；**无状态**（每个请求独立）
- 无状态的解决方案：**Cookie**（客户端保存标识）+ Session（服务端保存状态）

### HTTP版本演进
| 版本 | 特点 |
|------|------|
| HTTP/1.0 | 短连接，一次请求一个连接 |
| HTTP/1.1 | **持久连接**、管线化、Host字段 |
| HTTP/2 | 二进制分帧、**多路复用**、头部压缩、服务器推送 |
| HTTP/3 | 基于 **QUIC（UDP）**，解决队头阻塞，0-RTT |

### 请求报文结构
请求行（方法 + URL + 版本）+ 请求头 + 空行 + 请求体
- **GET**：无请求体，参数在URL，用于查询
- **POST**：数据在请求体，用于提交（表单、JSON）
- 其他：PUT、DELETE、HEAD、OPTIONS、PATCH

### 响应报文结构
状态行（版本 + 状态码 + 短语）+ 响应头 + 空行 + 响应体
- **状态码分类**：1xx信息、2xx成功（200）、3xx重定向（301/302）、4xx客户端错误（400/403/404）、5xx服务端错误（500/502/503）

## HTTPS
- HTTP + **TLS/SSL**，默认 **443** 端口
- 过程：非对称加密（RSA/ECC）协商会话密钥 → 对称加密（AES）传输数据
- 提供：机密性、完整性、身份认证（数字证书）
